# CLI-утилита «Сводка по городу»

Консольное приложение на Python для получения текущей информации о погоде и курсах валют по выбранному городу. Приложение обращается к внешним REST API (Open-Meteo и Frankfurter), обрабатывает данные по установленным правилам и выводит результат в консоль или в формате JSON.

---

## 📋 Требования к окружению

- Python 3.10 или выше
- Зависимости из `requirements.txt`

---

## 🚀 Установка и настройка

1. **Клонируйте репозиторий** или скачайте исходный код проекта.

2. **Создайте и активируйте виртуальное окружение** (рекомендуется):
   ```bash
   python -m venv venv
   
   # Для Linux / macOS:
   source venv/bin/activate

   # Для Windows:
   venv\Scripts\activate
   ```

3. **Установите зависимости**:
   ```bash
   pip install -r requirements.txt
   ```

---

## 💻 Использование

Запуск осуществляется через файл `main.py` с обязательным указанием параметра `--city`.

### Основные аргументы CLI:

| Флаг | Описание | Обязательный | Значение по умолчанию |
| :--- | :--- | :---: | :---: |
| `--city` | Название города для прогноза погоды | **Да** | — |
| `--currency` | ISO-код валюты по отношению к RUB | Нет | `USD` |
| `--json` | Вывод результата в формате JSON | Нет | `False` |

---

## 📝 Примеры команд

1. **Базовый запуск** (погода в Москве, курс USD по умолчанию):
   ```bash
   python main.py --city Moscow
   ```

   **Пример вывода:**
   ```text
   Город: Moscow
   Погода: -3.2°C, Clear sky
   Тёплая одежда: да
   USD→RUB: 92.15
   Дорогой курс: нет
   ```

2. **Указание другой валюты** (например, EUR):
   ```bash
   python main.py --city Moscow --currency EUR
   ```

3. **Получение результата в формате JSON**:
   ```bash
   python main.py --city Berlin --currency USD --json
   ```

   **Пример вывода:**
   ```json
   {
     "city": "Berlin",
     "weather": {
       "temp_c": 14.5,
       "description": "Mainly clear",
       "warm_clothes": false
     },
     "rates": {
       "currency": "USD",
       "rate_to_rub": 91.20,
       "expensive": false
     }
   }
   ```

## 🚦 Коды выхода (Exit Codes)

Приложение возвращает следующие статусы завершения:

- **`0`** — Успешное выполнение.
- **`2`** — Ошибка CLI-аргументов (не переданы обязательные флаги или неверный формат).
- **`3`** — Данные не найдены (указанный город или код валюты отсутствуют в API).
- **`4`** — Внешний сервис недоступен (превышено максимальное количество попыток запроса).
